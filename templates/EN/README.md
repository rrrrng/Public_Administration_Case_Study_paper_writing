# EN Reference Directory

Place English public administration papers or theory notes that you have the right to use in this directory. They serve as theoretical anchors and writing references.

All `*.md`, `*.pdf`, `*.png`, and `*.jpg` files in this directory are excluded by the repository root `.gitignore` and will not be committed to the public repository.

Do not add:

- Full texts you are not licensed to redistribute.
- PDF conversions containing institutional names, library accounts, or download stamps.
- Materials containing personal data or sensitive unpublished fieldwork.
