## 正确的段落写法

### 语料库标准段落示范

#### 示范一：引入维度+证据展开（来自《数治幻觉》）

> "数字化治理的核心价值之一是通过准确数据支持精准治理，然而在实践中，数据质量问题却成为制约治理效能的关键因素。B市基层治理体系中的数据质量问题主要表现在三个方面：……一位社区工作者反映：'流动人口数据的准确率仅在60%-80%之间……'（访谈资料：A1-5-20230421）……系统中的数据更新严重滞后于现实变化……"

→ 特点：首句立论（判断句）→ 多层次展开（访谈+文件）→ 末句小结

#### 示范二：主体应对（来自《数治幻觉》）

> "面对数字化治理体系中的结构性矛盾，基层治理主体展现出显著的能动性，形成了一系列具有特定逻辑的策略性应对机制。在应对考核压力方面，基层治理主体普遍采取了选择性回应与数据调适策略……调研显示，以社交媒体群组为核心的非正式沟通网络已成为基层治理的实际运行平台……"

→ 特点：引入主体能动性 → 展开具体策略 → 描述效果

## 段落写作检查清单

- [ ] 首句是否为完整判断句（而非"首先……"或"值得关注的是……"）
- [ ] 证据引用后是否紧跟分析句（"这表明/说明/揭示了……"）
- [ ] 是否避免了标签化框架（不用"冲突触发""机制判断"等）
- [ ] 核心证据是否标注来源
- [ ] 段落末句是否做了小结或过渡

## 访谈材料标注格式（语料库标准）

```
[访谈记录-地区-序号-YYYYMMDD]
例如：[访谈记录-A1-5-20230421]
```

编码规则说明：
- 地区：用字母编码（如A1表示某市某区）
- 序号：受访者编号
- YYYYMMDD：访谈日期

**禁止使用旧格式**：
- ✗ `[访谈记录-20221208, H省团省委干部R]`
- ✗ `[村民访谈记录，20230505-HSC-YM]`
