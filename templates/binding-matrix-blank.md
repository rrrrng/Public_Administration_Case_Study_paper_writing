# Theory-Case Binding Matrix（理论案例绑定矩阵）

本模板用于 Phase 1，将案例中浮现的核心张力与既有理论锚点进行系统绑定，明确绑定方式和体例位置。

---

## 绑定矩阵（4列格式）

| 案例张力/观察 | 理论锚点 | 绑定方式 | 体例位置 |
|-------------|---------|---------|---------|
| [案例中观察到的核心矛盾或反常现象，用一句话描述] | [对应的既有理论/概念/命题] | 直接 / 部分 / 反向 / 拒绝 | 发现一 / 发现二 / 发现三 / 第X节 |
| | | | |
| | | | |
| | | | |
| | | | |

---

## 绑定方式说明

| 绑定方式 | 含义 | 何时使用 |
|---------|------|---------|
| **直接** | 案例直接证实了某理论的核心命题 | 理论框架在案例中得到验证 |
| **部分** | 案例在某条件下限定或补充了某理论 | 理论在案例中出现边界/例外 |
| **反向** | 案例显示某理论在现实中不成立 | 发现与理论预期相反 |
| **拒绝** | 既有理论无法解释本案例 | 无现成理论可用，需概念建构 |

---

## 使用说明

1. **行数不固定**，按案例实际张力数量生成
2. 绑定矩阵在 **Phase 1** 完成后生成草稿，供用户确认后进入 Phase 2
3. 理论锚点的选取标准：该理论必须能**解释或部分解释**案例中的某一观察
4. 不要求穷尽性绑定——聚焦与研究发现直接相关的张力即可
5. 详细写作规范参见 `references/writing-guide.md`

## 示例（来自语料库，仅作格式参考）

| 案例张力/观察 | 理论锚点 | 绑定方式 | 体例位置 |
|-------------|---------|---------|---------|
| "弱资源"共青团在考核中排名靠后，却仍能推动"县域试点"落地 | 传统组织激励理论（资源→激励） | 部分 | 发现一 |
| H省团省委与A区党委对同一政策存在对立性叙事 | 整体性治理理论（协调困境） | 直接 | 发现二 |
| 弱势部门的政策叙事经历"矛盾→调适→共识"的演变过程 | 政策叙事理论 | 部分 | 发现三 |

---

## 理论对话的四种结果（指导绑定方式选择）

| 结果 | 对应绑定方式 | 描述 |
|------|-----------|------|
| 直接支撑 | 直接 | 案例证实了理论的核心假设 |
| 部分修正 | 部分 | 案例在某条件下限定了理论 |
| 反向否定 | 反向 | 案例显示理论在现实中不成立 |
| 概念建构 | 拒绝 | 案例启发了一个新概念 |
