# Claim-Evidence Matrix（论点—证据链矩阵）

用于 Phase 2，决定哪些判断可以进入正文。

| 核心论点/发现 | 论点类型 | 支撑证据 | 反向证据/例外 | 证据强度 | 正文位置 | 写作处理 |
|---|---|---|---|---|---|---|
|  | 现象描述/机制解释/理论命题/边界条件 | INT/DOC/OBS/DATA 编号 |  | A/B/C/D |  | 强论断/有限观察/删除 |

## 证据强度

- A级：一手访谈 + 文件/观察互证，可写为核心发现。
- B级：公开文件 + 多条公开材料互证，可写为稳健判断。
- C级：单一材料支持，只能写为有限观察。
- D级：无材料支持，不进入正文。

## 使用规则

1. 每个一级发现至少需要 A 或 B 级证据。
2. 机制链条中的每个关键环节都要有材料编号。
3. 有反向证据时不得删除，转入边界条件或替代解释讨论。
4. 证据不足时降低论断强度，不用修辞掩盖材料缺口。
