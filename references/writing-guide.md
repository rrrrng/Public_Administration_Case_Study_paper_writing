# 公共管理学报式案例研究写作导则

本导则服务于《公共管理学报》式公共管理案例研究论文生成。以 `templates/CN/` 范文为最高优先级，并以 `references/cn-exemplar-benchmark.md` 作为成稿质量基准。采用“功能完整、标题弹性”的原则：不机械固定 6 节或 7 节，而是根据案例任务匹配概念建构型、机制解释型、行动策略型或框架归纳型。

## 1. 体例骨架：功能固定，标题弹性

所有成稿必须覆盖七项功能：

1. 问题提出：从具体现象或治理悖论进入，提出研究问题。
2. 文献/理论对话：说明已有研究解释了什么、遗漏了什么。
3. 研究设计：交代案例选择、资料来源、分析单元、研究边界。
4. 案例呈现：交代案例背景、时间线、关键情境，不提前堆结论。
5. 案例分析：按维度、线索追踪、行动策略或生成逻辑展开。
6. 机制/理论提升：构建机制模型、理论命题、边界条件。
7. 结论讨论：总结发现、理论贡献、实践启示、局限与展望。

标题可合并。例如“文献回顾与问题提出”“研究方法与案例描述”“案例分析与研究发现”“结论与讨论”均可接受，前提是功能完整。

## 2. 范文体例选择

| 体例 | 适合任务 | 案例分析组织方式 |
|---|---|---|
| 概念建构型 | 需要命名新概念或治理模式 | 从案例变化中抽取概念要素 |
| 机制解释型 | 解释反常现象或治理悖论 | 因果链、过程追踪、机制图 |
| 行动策略型 | 解释牵头部门/基层组织如何行动 | 主体策略、资源动员、互动过程 |
| 框架归纳型 | 从经验中提炼多维框架 | 多场景比较、耦合模型 |

开始写作前，必须先读取 `references/cn-exemplar-benchmark.md`。写作或修改引言、问题提出、研究背景时，同时读取 `references/introduction-writing-module.md`，再从 `templates/CN/` 中选择 2–3 篇相近范文，输出“范文匹配说明”“开篇问题链”“摘要骨架”和“理论贡献预判”。

## 3. 句子级规范

- 句首直接点题，少用“值得注意的是”“事实上”等空泛铺垫。
- 保留公共管理中文论文常见名词化表达，如“制度逻辑”“生成机制”“治理效能悖论”。
- 每段采用“首句立论 → 材料展开 → 句末判断/过渡”的结构。
- 案例材料必须有来源标记，访谈按 `[访谈记录-地区-序号-YYYYMMDD]` 标注。
- 不把内部分析步骤写成正文标题，禁止正文出现“冲突触发/材料碰撞/机制判断/理论落点”四步标签。
- 严格限制“不是……而是……”“并非……而是……”“不只是……更是……”“不仅……而且……”“只有……才……”等强逻辑句式。写作这类辩证逻辑段落前，先回答该段指向本文需要解决的什么问题、解决了预期结果中的哪一部分、删除后论证结构是否仍完整；只有存在材料支撑的前后对比、主体差异、理论碰撞或替代解释处理时才使用，否则改为平实分析句。

## 3.0 篇幅规范

完整中文正文默认控制在 15000-17000 字，不含参考文献、附录和材料清单。生成完整论文前先按 `references/manuscript-length-control.md` 输出章节篇幅预算，生成后复核各章节估算字数。篇幅不足时优先补案例分析、过程追踪、机制提升和替代解释；篇幅超出时优先压缩泛化背景、重复文献和重复结论。

## 3.1 开篇与摘要规范

- 引言不只是介绍主题，更应该构造问题；主题介绍回答“研究什么”，问题构造回答“为什么值得研究、已有解释为何不足、本文如何回答”。
- 开篇必须形成“现实变化/治理任务 → 结构重塑/主体变化 → 经验反常/治理悖论 → 文献缺口 → 研究问题 → 案例与方法”的问题链。
- 开头背景句优先采用“宏观驱动力 → 机制解释 → 行为转化 → 现象落地”的微结构，避免从“随着社会发展”直接跳到研究对象。
- 摘要采用“背景问题 → 案例方法 → 主要发现 → 机制解释 → 理论贡献/实践启示”的五句结构。
- 文献回顾按“研究传统 → 可解释对象 → 解释不足 → 本文入口”推进，不能做百科式堆叠。
- 理论贡献写成概念贡献、机制贡献、边界贡献或情境贡献之一，不能只写“丰富了相关研究”。

## 4. 段落级规范

案例分析段落必须同时包含三类信息：

1. 理论判断：本段解释什么机制、策略或表现。
2. 案例证据：访谈、文件、观察、统计或公开材料。
3. 分析推进：证据如何支持判断，并如何连接下一层机制。

弱证据只能支撑有限观察，不能支撑强机制命题。

每个案例分析段落还必须体现至少一种分析动作：主体策略识别、资源重组说明、制度约束解释、技术条件解释、组织互动追踪、结果偏差辨析或边界条件限定。材料之后必须解释“该材料如何支持本段判断”。

## 5. 图表规范

优先生成以下图表：案例时间线图、主体关系图、概念谱系图、理论区隔表、证据链矩阵、机制模型图、替代解释排除表。图表标题必须是完整判断句，不写成短语堆砌。
