# Qualitative Analysis Workflow

用于把真实材料或模拟材料转化为公共管理案例论文的发现、机制和理论命题。

## 1. 材料预处理

先建立材料编号：

- `I`：真实访谈。
- `D`：政策文件、制度文本、新闻材料。
- `O`：观察记录、场景记录。
- `S`：统计或平台数据。
- `SI/SD/SO/SE`：模拟访谈、模拟文件、模拟观察、模拟事件。

每条材料记录来源、时间、主体、可引用性和对应论文位置。

## 2. 开放编码

从材料中抽取：

- 事件：发生了什么。
- 主体：谁在行动。
- 行动：采取了什么策略。
- 资源：动员或缺少什么资源。
- 制度：受到什么规则、考核或职责边界约束。
- 技术：平台、数据、算法、接口如何影响行动。
- 互动：主体之间如何协调、推诿、合作或冲突。
- 结果：产生了什么治理绩效、偏差或副作用。

## 3. 轴心编码

把开放编码聚合为三类结构：

| 结构 | 说明 | 示例 |
|---|---|---|
| 分析维度 | 制度、组织、技术、资源、主体、情境 | 技术标准重塑部门协同 |
| 过程链条 | 前置条件、触发事件、行动策略、互动过程、结果 | 考核压力触发数据填报策略 |
| 理论类别 | 概念、机制、命题、边界条件 | 数治幻觉、制度趋同 |

## 4. 选择性编码

确定一个核心解释对象：

- 新概念：命名过去理论未充分解释的现象。
- 生成机制：解释现象如何发生。
- 行动策略：解释主体如何在约束中行动。
- 框架模型：概括多维因素如何耦合。

只保留服务核心解释对象的编码。边缘材料进入附录或材料缺口。

## 5. 过程追踪

每条机制链写成：

`前置条件 → 触发事件 → 主体判断 → 行动策略 → 主体互动 → 中间结果 → 最终结果`

每个节点绑定材料编号。没有材料编号的节点只能写为待校准假设。

### 机制链可审计规则

每条机制链必须通过以下检查：

- 每个节点绑定真实材料编号、模拟材料编号或“待补充”标记。
- 至少包含一个主体策略节点，说明行动者如何在约束中选择、协同、规避、转换或抵抗。
- 至少包含一个制度、资源、技术或组织条件节点，说明机制发生的情境基础。
- 至少包含一个中间结果节点，避免从原因直接跳到最终结果。
- 至少能转写成一个理论命题，说明在何种条件下，何种主体通过何种策略影响何种结果。

未通过上述检查的链条只能作为分析假设，不能作为正文中的核心机制。

## 6. 替代解释和反例

至少保留两个替代解释：

- 资源解释：是否只是资源多寡导致结果？
- 领导解释：是否只是领导重视导致结果？
- 技术解释：是否只是平台工具导致结果？
- 考核解释：是否只是压力型考核导致结果？
- 文化解释：是否与地方治理传统相关？

逐一说明材料如何支持、限定或排除这些解释。

## 7. 输出格式

完成质性分析后输出：

- 开放编码表。
- 轴心编码表。
- 过程追踪链条。
- 论点—证据链矩阵。
- 替代解释表。
- 理论命题或机制模型。
