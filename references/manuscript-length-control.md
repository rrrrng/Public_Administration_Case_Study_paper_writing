# 成稿篇幅控制模块

本模块用于完整论文生成、扩写、压缩和阶段性改稿。默认完整中文案例研究论文目标为 **15000-17000 中文字**，不含参考文献、附录和材料清单；若用户或期刊另有要求，以用户明确要求为准。

## 1. 默认篇幅目标

- 完整论文正文：15000-17000 中文字。
- 摘要：300-500 中文字。
- 关键词：3-5 个。
- 参考文献、附录、访谈提纲、材料编号表不计入正文字数，除非用户明确要求合并计算。

若材料只能支撑较短论文，不得用背景、文献综述或空泛政策意义填充篇幅；应说明材料不足，降低目标字数或把机制判断写为待验证假设。

## 2. 章节篇幅预算

| 章节功能 | 建议字数 | 控制重点 |
|---|---:|---|
| 摘要 | 300-500 | 背景、方法、发现、机制、贡献完整 |
| 问题提出 | 1800-2200 | 问题链清楚，避免政策背景堆叠 |
| 文献回顾/理论基础 | 2500-3200 | 解释边界和本文入口，不做百科式综述 |
| 研究设计 | 1200-1600 | 案例选择、资料来源、分析单元、边界 |
| 案例呈现 | 1800-2400 | 时间线、主体、情境，不提前堆结论 |
| 案例分析 | 4500-5500 | 材料、判断、解释和推进最密集 |
| 机制模型与理论提升 | 2200-3000 | 机制链、命题、边界、替代解释 |
| 结论讨论 | 1000-1500 | 发现、贡献、启示、局限 |

根据体例可以合并标题，但功能预算仍需保留。例如“文献回顾与问题提出”合并时，应同时覆盖问题提出和文献对话的篇幅功能。

## 3. 篇幅调整顺序

扩写时优先补：

1. 案例分析中的材料展开和材料后的解释。
2. 过程追踪中的关键节点、主体行动和互动过程。
3. 替代解释、反例和边界条件。
4. 文献回顾中的解释边界和理论入口。

压缩时优先删：

1. 泛化政策背景和重复重要性表述。
2. 未进入研究问题的文献罗列。
3. 没有材料编号支撑的机制判断。
4. 重复的概念解释和空泛启示。

## 4. 生成前后检查

生成完整正文前，先输出篇幅预算表，列出各章节目标字数。生成后输出篇幅复核表，标明估算字数、超出或不足的章节、调整建议。

若总字数低于 15000，先检查是否缺少案例分析、机制提升或替代解释；若总字数高于 17000，先压缩背景、文献罗列和重复结论，不压缩核心材料与机制分析。
