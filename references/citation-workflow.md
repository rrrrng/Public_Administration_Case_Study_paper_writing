# 引文处理工作流

本文件为《公共管理学报》个案研究论文的引文处理规范，涵盖来源、抓取格式、密度控制和常见错误。

---

## 一、引文原则

### 核心原则（三不）

- **不虚构**：所有引文必须可查证，不确定的标注`[引文待核实]`
- **不贴标签**：每篇引文必须说明"该文献说明了什么/与本文什么关系"，禁止人名+年份堆砌
- **不干扰体例**：引文服务于理论对话，不服务于展示阅读量

### 引文相关性优先

每引用一篇文献，必须回答：
1. 该文献**说明了什么**（描述性）
2. 该文献**与本文理论对话的直接关系**是什么（分析性）
3. 本文**在哪个层面修正/补充/限定了该文献**（贡献性）

> **例**（来自语料库，正确示范）："Margetts 和Dunleavy 指出，在政府数字化转型过程中，技术系统的复杂性往往与组织结构、管理文化和既有流程相互作用，可能影响整体效能的提升[3]。"

> **错误示范**："Margetts 和Dunleavy（2013）研究了数字化治理问题。"

## 二、引文密度控制（按 section）

基于《公共管理学报》10 篇语料库的观察，规定各节引文数量如下：

| Section | 引文数量 | 说明 |
|---------|---------|------|
| 问题提出 | 10-15 篇 | 理论背景+现象描述，需要密集引文建立问题合法性 |
| 文献综述与理论视角 | 8-12 篇 | 只引与理论对话直接相关的，不做大综述 |
| 研究设计与案例呈现 | 3-5 篇 | 方法论引文为主，案例描述不依赖引文 |
| 案例分析与研究发现 | 3-5 篇 | 材料叙述为主，引文只用于标注理论锚点 |
| 理论提升与讨论 | 5-8 篇 | 理论对话引文，优先近5年文献 |
| 结论与展望 | 0-2 篇 | 基本不引，重在总结 |

**总引文量建议**：40-60 篇（个案例研究标准规模）

## 三、中文文献来源与抓取

### 推荐来源

| 类型 | 来源 | 格式 |
|------|------|------|
| 期刊论文 | CNKI（知网） | 作者. 标题[J]. 刊名, 年份, 期: 页码. |
| 学位论文 | CNKI | 作者. 标题[D]. 学位授予单位, 年份. |
| 政府文件/皮书 | 国务院政策文件库/皮书数据库 | 机构. 标题[EB/OL]. 发布日期. URL |
| 报纸文章 | CNKI/人民网 | 作者. 标题[N]. 报纸名, 日期. |
| 英文文献 | Google Scholar / Semantic Scholar | 按期刊格式 |

### 抓取步骤

1. **确定核心概念**：从研究问题中提取 3-5 个核心关键词
2. **CNKI 搜索**：以核心关键词搜索，筛选近 5 年高被引论文
3. **参考文献追溯**：从高被引论文的参考文献中补充经典文献
4. **质量筛选**：优先选择《公共管理学报》《中国行政管理》《公共管理评论》《社会学研究》等 CSSCI 来源刊
5. **英文补充**：检索该领域的英文顶刊（PAR/JPART/PMR），补充国际对话

### 查重与整理

- 建议使用 Zotero 管理文献，支持 CNKI 直接导入
- 导出时选择 GB/T 7714 格式
- 引用前用 CNKI 或 Google Scholar 核实作者、年份、页码

## 四、引文格式规范

### 《公共管理学报》要求的顺序编码制

#### 期刊论文

```
[序号] 作者. 标题[J]. 刊名, 年份, 期: 页码.

例：
[1] 周雪光. 中国国家治理的制度逻辑：一个组织学研究[M]. 北京: 生活·读书·新知三联书店, 2017: 56-78.
```

#### 英文期刊

```
[序号] Author A, Author B. Title of article[J]. Journal Name, Year, Volume(Issue): Page-Page.

例：
[5] MARGETTS H, DUNLEAVY P. The Second Wave of Digital-era Governance[J]. Philosophical Transactions of the Royal Society A, 2013, 371(1987): 20120382.
```

#### 政府文件

```
[序号] 发布机构. 文件标题[EB/OL]. 发布日期. URL.

例：
[2] 中共中央, 国务院. 数字中国建设整体布局规划[EB/OL]. 2023. https://www.gov.cn/zhengce/2023-02/27/content_5742224.htm
```

### 格式检查

- [ ] 正文引用处编号顺序排列（[1][2][3]而非[3][1][2]）
- [ ] 所有编号在参考文献中都有对应条目
- [ ] 参考文献中无遗漏的编号
- [ ] 作者姓名大小写正确（中文文献不涉及，英文首字母大写）
- [ ] 刊名/书名使用斜体（LaTeX 下用 `\emph{}` 或 `\textit{}`）

## 五、引文核实规则

### 可直接使用

- 通过 CNKI/Google Scholar 可查证的文献
- 官方发布的政府文件
- 已在其他论文中引用过的文献（通过二次查证确认）

### 标注`[引文待核实]`

- 只记得大概年份和作者，无法核实具体页码
- 从二手文献中转引（注明"转引自"）
- 网络来源无法验证权威性

> **例**（待核实的正确处理）："有研究表明……[引文待核实：周雪光，国家治理的制度逻辑，具体年份和出版社需查证]"

### 禁止行为

- **虚构作者、年份、期刊名**
- **用"相关研究表明""有学者指出"代替具体引用**（除非确实无法查证，且标注待核实）
- **用大模型生成不存在的 DOI 或 URL**

## 六、常见错误

| 错误 | 正确做法 |
|------|---------|
| 引文数量过多（问题提出写了 40+ 篇引文） | 按密度控制表精简，每篇引文必须有明确功能 |
| 贴标签式引用（"王五（2020）研究了X"） | 说明该文献的具体观点及与本文的关系 |
| 引用过时文献（20 年前的中文文献当主力） | 主力引文应为近 5 年，近期经典可保留 |
| 正文引用编号与参考文献不对应 | 写完后用 Word/Zotero 交叉检查编号 |
| 英文文献格式错误（刊名不斜体、作者写错） | 用 Zotero 或 Google Scholar 导出格式后核对 |

## 七、引文与 Theory-Case Binding Matrix 的配合

引文的首要功能是服务于 Theory-Case Binding Matrix 中的"理论锚点"。

每行 Binding Matrix 对应 1-3 篇核心引文，这些引文需要：
1. 在文献综述 section 中有完整呈现
2. 在 Binding Matrix 中标注体例位置
3. 在发现部分引用时，指向矩阵中的编号

> **工作流**：先构建 Binding Matrix → 从矩阵推导所需引文 → 按密度控制表分配到各节
