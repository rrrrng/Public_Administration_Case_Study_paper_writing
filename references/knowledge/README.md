# Knowledge Base (PA Case Study Writing)

This folder contains reusable writing structures and reviewer-response tactics for **public administration case study papers**.

Files:
- `structure.md`: manuscript structure and argument scaffolds (case -> mechanism -> propositions -> contribution)
- `writing-techniques.md`: sentence/paragraph patterns with PA-style examples
- `submission-guides.md`: common reject points + pre-submission compliance checks (generic)
- `review-response.md`: response-to-review templates and common comment-to-action mappings
