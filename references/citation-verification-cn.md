# 中文公共管理引文核验规则

## 基本原则

- 不虚构作者、年份、题名、期刊、卷期、页码。
- 不能核实的文献统一标记 `[引文待核实]`。
- 优先使用用户提供的文献库、Zotero、PDF、CNKI/万方/维普/Google Scholar 可查信息。

## 写作时的占位格式

- 理论来源不确定：`[理论来源待核实：关键词]`
- 具体文献不确定：`[引文待核实：作者/主题/年份线索]`
- 页码不确定：`[页码待核实]`

## 核验清单

| 检查项 | 要求 |
|---|---|
| 作者 | 与原文一致 |
| 年份 | 与发表年份一致 |
| 题名 | 不自行改写 |
| 刊名 | 使用正式刊名 |
| 卷期页码 | 可缺省但不得编造 |
| 正文引用 | 与参考文献一一对应 |

## 禁止行为

- 为了“看起来学术”添加不存在的经典文献。
- 把相似主题文献写成支持特定命题的证据。
- 将英文理论随意对应到中文作者而不核验。
