# CN 范文抽取方法

从 `templates/CN/` 学习时，不要整篇照读或泛泛模仿。只抽取可迁移的结构和功能。

## 1. 抽取顺序

1. 标题结构：主标题、冒号前概念、副标题案例对象。
2. 摘要结构：背景、方法、发现、机制、贡献。
3. 开篇问题链：现实变化、经验反常、文献缺口、研究问题。
4. 一级标题树：每节承担的论文功能。
5. 研究设计：案例选择、资料来源、方法说明、可信度处理。
6. 案例分析段落：首句判断、材料类型、解释动作、段末推进。
7. 机制表达：概念、维度、链条、模型图、命题。
8. 结论贡献：理论贡献、实践启示、边界条件。

## 2. 抽取输出

使用 `templates/exemplar-extraction-template.md`。每篇范文最多抽 1 页等量信息，避免把范文全文塞入上下文。

完成抽取后输出“迁移评分表”，逐项标记是否已经迁移到当前论文设计：

| 项目 | 抽取内容 | 是否已迁移 | 不足与修复 |
|---|---|---|---|
| 标题节奏 | 主标题、副标题、概念位置、案例对象 | 是/否 |  |
| 开篇问题链 | 现实变化、经验反常、文献缺口、研究问题 | 是/否 |  |
| 摘要句法 | 背景、方法、发现、机制、贡献 | 是/否 |  |
| 案例分析段落 | 判断、材料、解释、推进 | 是/否 |  |
| 机制表达 | 链条、模型、命题或概念维度 | 是/否 |  |
| 贡献表达 | 概念、机制、边界或情境贡献 | 是/否 |  |

若任一核心项为“否”，先修复当前论文设计，再进入正文生成。核心项包括开篇问题链、案例分析段落、机制表达和贡献表达。

## 3. 迁移规则

- 迁移章节功能，不复制句子。
- 迁移问题链，不复制案例事实。
- 迁移段落推进方式，不复制论证对象。
- 迁移机制表达，不复制概念名称，除非研究对象确实相同。

## 4. 匹配建议

- 数字治理、平台治理、基层负担：优先看“数治幻觉”“数字化协同”。
- 牵头部门、协同治理、风险防控：优先看“以数增权”。
- 新治理模式或新概念：优先看“融合型政府”“制度趋同”“整体治理观”。
- 试点执行、地方创新、政策执行：优先看“开放试点”。
- 智慧养老、技术—组织—环境：优先看“TOE框架”“四力耦合”。
