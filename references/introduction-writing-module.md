# 引言写作模块：从主题介绍到问题构造

本模块用于写作或修改中文公共管理、公共行政与社会科学案例研究论文的引言。引言不只是介绍主题，更应该构造问题。主题介绍回答“本文研究什么”，问题构造回答“为什么这个主题值得研究、已有解释为何不足、本文准备如何回答”。如果引言只完成主题介绍，读者知道对象却未必认可研究必要性；如果引言完成问题构造，读者会沿着逻辑链进入研究问题。

## 1. 引言的核心任务

引言至少完成四项任务：

1. **建立研究语境**：把研究对象放入一个有现实意义和学术意义的宏观领域中。
2. **收束已有研究**：概括既有研究的主要路径、解释对象和共同盲区，而不是提前堆叠文献综述。
3. **显现研究缺口**：指出已有研究未能解释、未充分解释或未覆盖的现象、机制、主体或情境。
4. **导出研究设计**：说明本文研究什么案例、用什么材料和方法、沿着什么路径分析、预期贡献是什么。

引言不是把背景、文献、方法和贡献机械拼接起来，而是把它们组织成一条连续的问题链。

## 2. 整体推进：四层引言结构

### 第一层：宏观领域建立

先说明研究对象处在什么现实变化、治理任务或学术领域中。写作重点不是泛泛声称“重要”，而是说明它为什么重要。

可用句式：

```text
近年来，随着【制度/技术/社会/组织变化】持续推进，【治理领域/公共问题】的运行逻辑正在发生变化。
```

避免写法：

- “随着社会发展，某问题越来越重要。”
- “某政策具有重要意义，因此值得研究。”
- 只罗列政策文件，不说明问题张力。

### 第二层：研究现状收束

概括已有研究主要从哪些路径理解该问题。不要按作者逐篇罗列，而要提炼研究传统、解释对象和解释边界。

推荐结构：

```text
既有研究主要从【路径一】、【路径二】和【路径三】展开，解释了【已能解释的对象】。
```

这一层的功能是让读者看到：研究基础已经存在，但其关注重心也形成了边界。

### 第三层：研究缺口显现

在承认已有研究贡献的基础上指出不足。缺口不能只写“研究较少”，而要说明“少在哪里、为什么这会影响解释”。

高质量缺口通常来自：

- 解释层级不足：能解释宏观制度，不能解释微观主体策略。
- 过程机制不足：能描述结果，不能解释变化如何发生。
- 情境边界不足：能解释一般情境，不能解释中国地方治理或特定组织场景。
- 主体经验不足：忽视特定群体、牵头部门、基层执行者、服务对象或平台方的行动逻辑。
- 理论张力不足：既有理论预期与案例经验之间出现偏差、悖论或反常。

可用句式：

```text
不无遗憾的是，现有研究虽然揭示了【已有解释】，但对【未被充分解释的对象/过程/主体/情境】关注不足，因而难以解释【本文案例中的经验反常或治理悖论】。
```

### 第四层：研究设计导出

当研究必要性已经成立后，再交代本文如何研究。引言后半部分至少说明研究对象、材料来源、方法路径和贡献类型。

可用句式：

```text
基于此，本文以【案例/场景】为研究对象，结合【材料类型】并采用【方法】，考察【核心研究问题】，进而揭示【机制/策略/概念/框架】，以期形成【理论贡献类型】。
```

## 3. 开头背景句：四步微结构

引言第一句话或第一组句子应尽量完成从现实变化到研究现象的导入。可以使用“四步微结构”：

1. **宏观驱动力**：什么趋势、制度、技术或社会变化正在发生。
2. **机制解释**：这种变化如何打破、重塑或改变原有结构。
3. **行为转化**：研究对象因此出现什么新行为、新关系或新处境。
4. **现象落地**：具体研究现象为何变得普遍、突出或值得解释。

模板：

```text
随着【趋势一】与【趋势二】的【发展/普及/推进】，【某领域】正在发生变化。
这种变化【打破/重塑/重构了】【原有约束或结构】。
这使得【研究对象】不再局限于【旧条件】，而是逐渐形成【新行为/新关系/新处境】。
由此，【研究现象】成为【越来越普遍/日益突出/亟待解释】的公共管理现象。
```

四步可以写成一句长句，也可以拆成二至四个短句。关键不是句子数量，而是逻辑链完整。

## 4. 与公共管理案例论文的衔接

公共管理案例论文的引言应把“重要性”转化为可解释问题。推荐问题链：

```text
现实变化/治理任务 → 结构重塑/主体变化 → 经验反常/治理悖论 → 文献解释边界 → 研究问题 → 案例与方法
```

不同体例可有不同侧重：

- **概念建构型**：从新现象或新实践中导出“现有概念不足以命名”的问题。
- **机制解释型**：从政策预期与运行结果之间的偏差导出“何以发生”的问题。
- **行动策略型**：从资源约束、职责错位或组织压力导出“主体如何行动”的问题。
- **框架归纳型**：从多维实践经验导出“如何形成解释框架”的问题。

## 5. 常见失败写法

- **只介绍主题**：读者知道研究对象，但不知道为什么值得研究。
- **空泛背景**：用“随着社会发展”“时代进步”等替代具体驱动力。
- **直接点题**：开头直接说“本文研究某问题”，没有语境、张力和缺口。
- **文献堆叠**：把引言写成作者罗列，缺少研究路径收束。
- **缺口虚弱**：只说“相关研究较少”，没有解释为什么少会造成理论问题。
- **研究设计突兀**：没有完成问题构造，就直接交代案例、方法和贡献。

## 6. 自检清单

写完引言后逐项检查：

- [ ] 是否既介绍了主题，又把主题构造成可研究的问题？
- [ ] 开头是否出现具体驱动力，而不是空泛时代背景？
- [ ] 是否说明现实变化如何改变原有结构或主体行为？
- [ ] 是否把研究现象落到一个具体、可观察、可解释的问题上？
- [ ] 是否概括了已有研究的主要路径，而不是逐篇罗列文献？
- [ ] 是否指出已有研究的解释边界，而不是只写“研究较少”？
- [ ] 是否形成“现实变化/治理任务 → 经验反常/治理悖论 → 文献缺口 → 研究问题”的链条？
- [ ] 是否顺势导出研究对象、材料、方法、分析路径和贡献类型？
- [ ] 是否避免政策宣传腔、工作总结腔和单向度表扬案例？
