# 迭代返工规则

本 skill 不是一次性生成器。每一轮输出都要判断是否需要返回前序阶段，直到问题链、证据链、机制链和范文体例形成闭环。

## 1. 返工触发信号

| 问题 | 表现 | 返回阶段 | 修复动作 |
|---|---|---|---|
| 问题意识弱 | 开篇只有政策背景和重要性 | Phase 0/0A | 增加经验反常、主体冲突、制度张力 |
| 范文匹配弱 | 只说“参考某范文”，没有抽结构 | Phase 1 | 使用 `references/exemplar-extraction.md` 重抽标题树和段落功能 |
| 文献综述散 | 按作者罗列，缺少解释边界 | Phase 1/3 | 重写为“研究传统—解释对象—解释不足—本文入口” |
| 材料支撑弱 | 论点没有材料编号或材料只证明现象 | Phase 2 | 补证据矩阵、过程追踪、反例材料 |
| 分析像总结 | 只写做法、成效、经验 | Phase 4 | 改写为“判断—材料—解释—推进” |
| 机制像清单 | 只有因素，没有因果链 | Phase 5 | 写成前置条件、触发、策略、互动、结果、命题 |
| 贡献虚 | 只写“丰富了研究” | Phase 5 | 改为概念贡献、机制贡献、边界贡献或情境贡献 |
| 摘要空 | 没有方法、发现或贡献 | Phase 6 | 按五句摘要重写 |

## 2. 每轮返工输出

使用 `templates/revision-note-template.md` 记录：

- 当前问题。
- 返回阶段。
- 修复动作。
- 保留内容。
- 删除内容。
- 新增材料或新增判断。
- 下一步。

## 3. 停止条件

满足以下条件后进入全文生成：

- 至少匹配 2 篇 CN 范文并完成范文抽取。
- 开篇问题链完整。
- 每个核心发现有证据链或模拟证据链。
- 文献回顾有明确解释边界。
- 案例分析段落能体现机制推进。
- 理论贡献属于四类之一。
