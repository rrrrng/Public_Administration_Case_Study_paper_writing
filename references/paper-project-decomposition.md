# 论文项目拆解模块

本模块用于把论文选题和写作推进视为一个可管理的小项目。核心原则是：先锁定交付物，再组织路径、材料和版本。论文的交付物不是“写完一篇文章”，而是一条能被复述、能被证据支撑、能被限定边界的研究结论。

写作启动、选题发散、材料不足、逻辑漂移或用户只有主题方向时，先执行本模块，再进入案例档案、范文匹配和正文生成。

## 1. 主交付物锁定

先判断本文主要交付哪一种结论。一次只锁定一种主交付物，其他想法进入扩展 backlog。

| 主交付物类型 | 交付问题 | 适用条件 | 风险 |
|---|---|---|---|
| 现象型结论 | 是什么、范围、程度如何 | 材料能清楚描述对象、范围和口径 | 容易停留在描述，理论贡献偏弱 |
| 差异型结论 | 哪里不同、在什么条件下更明显 | 有同口径可比材料、时间差异或群体差异 | 容易比较口径不一致 |
| 机制型结论 | 为什么发生、通过哪个关键环节 | 有过程证据、时间顺序、主体行动和互动材料 | 容易过度承诺，证据要求最高 |
| 框架型结论 | 如何归纳维度、路径或模型 | 材料能覆盖多个维度或多个阶段 | 容易变成因素清单 |

默认不要把一篇论文同时承诺为现象型、差异型和机制型。若用户要求完整机制论文，但材料只能支撑现象或差异，先降级主交付物，再把机制解释写为假设或下一篇计划。

## 2. 可用材料确认

材料确认不是把所有材料找齐，而是判断“能不能做、能做到什么强度”。至少回答三件事：

1. **材料来源**：来自访谈、政策文件、新闻报道、调研笔记、统计数据、平台材料、图片说明、模拟材料或用户口述。
2. **使用边界**：是否可合法使用、是否需要匿名化、是否可引用、是否为模拟生成。
3. **支撑强度**：材料能支撑现象描述、差异比较、机制解释还是只能支撑待验证假设。

按主交付物检查：

- 现象型结论：确认范围、口径、对象和材料覆盖度。
- 差异型结论：确认比较对象同口径、同时间或有明确差异条件。
- 机制型结论：确认有过程证据、事件顺序、主体行动、互动过程和中间结果。
- 框架型结论：确认材料足以支撑每个维度或阶段，不用空概念填补空白。

输出判断必须包含：`可做 / 降级后可做 / 暂不可做`。暂不可做时，列出最小补充材料清单。

## 3. 第一版结论句

在写背景和文献之前，先写一条第一版结论句。它不是最终结论，而是项目的临时终点，用于控制范围。

结论句必须包含：

- **对象**：研究的是谁、什么组织、什么政策场景或什么治理过程。
- **条件**：在哪种制度、技术、资源、时间或情境条件下。
- **结论点**：本文准备交付的核心判断。

模板：

```text
现象型：在【范围/场景】中，【对象】呈现出【现象特征】，其突出表现为【范围/程度/形态】。
差异型：在【条件】下，【对象A】相较于【对象B/既有状态】表现出【差异方向】，这一差异集中体现为【关键维度】。
机制型：在【前置条件】下，【对象】通过【关键环节/主体策略/互动过程】推动/导致【结果】，形成【机制名称或机制判断】。
框架型：围绕【治理任务/实践场景】，【对象】形成了由【维度一】、【维度二】和【维度三】构成的【框架/路径/模型】。
```

第一版结论句必须能被证据链矩阵逐步支撑。若无法为结论句中的关键词找到材料编号，降低结论强度或缩小研究范围。

## 4. 最小结果产出

在全文生成前，先产出一个最小可用结果，用来证明题目能够交付。最小结果可以是：

- 一条核心判断及其证据链。
- 一段“判断—材料—解释—推进”的核心案例分析段。
- 一张核心证据链表或机制草图。
- 一个可落地的比较表、时间线或过程追踪链条。

最小结果不要求语言完美，但必须回答：

1. 这条判断是否能被现有材料支撑？
2. 材料是否只证明现象，还是能证明差异或机制？
3. 这条判断是否值得扩展成完整论文？
4. 若不能扩展，应该降级、缩小还是暂停？

未产出最小结果前，不进入完整正文生成。

## 5. 扩展讨论与版本升级

写作中新增的想法必须进入版本管理，而不是直接塞进正文。把扩展内容分为两类：

| 类型 | 处理方式 | 示例 |
|---|---|---|
| 本篇必须写 | 纳入正文或讨论部分 | 边界条件、替代解释、核心反例、证据限制 |
| 本篇不必写 | 进入下一篇计划或后续研究 | 跨区域外推、完整政策方案、第二机制链、全面比较研究 |

本篇不必写的内容不要删除，可以保留为 `next-paper-backlog`。这样既保护本篇结论不被过度承诺拖垮，也能把一个方向拆成系列成果。

## 6. Phase 0 输出要求

执行本模块后，输出或填充 `templates/paper-project-brief-template.md`，至少包括：

- 主交付物类型。
- 可用材料确认与 go/no-go 判断。
- 第一版结论句。
- 最小结果产出计划。
- 本篇范围边界。
- 下一篇或后续研究 backlog。

用户确认项目简报后，再进入案例档案、范文匹配和后续阶段。

## 7. 返工触发

出现以下情况时，返回本模块：

- 论文同时承诺现象、差异、机制和政策方案，主线失控。
- 第一版结论句无法用一句话复述。
- 证据链只能支撑现象，却试图写成机制结论。
- 写作中不断追加新问题、新案例、新理论或新政策建议。
- 最小结果无法成立，但仍想通过扩写背景和文献掩盖问题。
